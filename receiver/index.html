No live camera? Record, then pick the video

Film the sender screen for a full loop with the phone's normal camera app (or tap the button, which opens the camera on most phones), then pick the clip here. It is decoded on the phone, offline — no camera permission for this page and no network needed. Works when this page is opened as a plain local file.

Point the camera at the sender screen. Order doesn't matter; missed frames come around again.

When the file is complete, Share… opens the phone's share sheet (WhatsApp, Mail, Drive, Files, AirDrop…). Save to phone puts it in Downloads / Files.

Optional: forward to an HTTP endpoint

Sends the raw bytes as the request body with X-Filename and X-SHA256 headers. The bundled server/receive_server.py accepts exactly this and re-verifies the hash.

Once opened over HTTPS, this page can be added to the home screen and then runs like an app, including with no connectivity.
